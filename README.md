# Lolka Music Bot

Музыкальный бот для [lolka.app](https://lolka.app) (российский аналог Discord): играет музыку с YouTube в голосовых каналах, ведёт очередь, плейлисты и локальный кеш треков.

## Возможности

- Воспроизведение YouTube-ссылок командой `!play <url>` или ссылкой в текстовом канале `#music`.
- **Поиск по YouTube**: `!play <текст>` в любом канале или свободное текстовое сообщение в `#music` — бот покажет результаты и ждёт выбора (реакция-цифра, ❌ — отмена). На сообщении «Сыграю: ...» появляется кнопка ➕ «В плейлист» — сохранить трек без команд.
- **Аудио-вложения**: прикрепи mp3/m4a/ogg/opus/flac/wav (до 64 МБ) к сообщению в `#music` — бот скачает и сыграет; такие файлы можно добавлять и в плейлисты (`!pl add` с прикреплённым файлом). Хранятся в `uploads/` (лимит 0.5 ГБ, LRU-очистка; файлы из плейлистов не удаляются).
- **Кнопки под «Сейчас играет»**: ⏮ предыдущий трек, ⏯ пауза/продолжить, ⏭ следующий, 🔁 цикл, ➕ добавить текущий трек в плейлист, ⏹ остановить и выйти — без команд в чат. Кликать могут участники того же голосового канала, что и бот.
- **Нормализация громкости** (EBU R128): треки приводятся к −14 LUFS (стандарт YouTube) — тихие и громкие ролики звучат одинаково. Измерение делается один раз при скачивании в кеш (для вложений — лениво), компенсация ±15 дБ с защитой от клиппинга.
- **Автовыход**: если в голосовом канале не осталось людей, бот через 10 секунд останавливает музыку и выходит (вернувшийся за это время человек отменяет выход).
- Очередь с навигацией: `!skip` / `!next` / `!prev`, повтор `!loop` (включён по умолчанию).
- Плейлисты на сервер (SQLite): создание, добавление, проигрывание, переименование, удаление; панель управления `!bot` с кнопками.
- Автосохранение треков из `#music` в плейлист `default`.
- Локальный кеш скачанных треков (Opus 96k, `cache/`, лимит 1.5 ГБ) с LRU-очисткой — YouTube-ссылки не истекают; кеш считается по использованию, а не по скачиванию.
- Фоновая предзагрузка: докачиваются только текущий и следующий треки, плейлист из 1000 треков не выкачивается целиком. `!play <url>` отвечает мгновенно — трек заигрывает по мере докачки.
- Голос через WebRTC (aiortc + pymediasoup), API совместим с discord.py.

## Команды

### Голос и очередь

| Команда | Описание |
| --- | --- |
| `!join` | Подключиться к голосовому каналу |
| `!play <url>` | Проиграть трек по ссылке (или добавить в очередь) |
| `!play <текст>` | Поиск по YouTube — выбери результат реакцией (❌ — отмена) |
| `!skip` / `!next` | Следующий трек |
| `!prev` | Предыдущий трек |
| `!loop` | Переключить цикл (по умолчанию включён) |
| `!pause` / `!resume` | Пауза / продолжить |
| `!now` | Текущий трек (с длительностью и ссылкой) |
| `!queue [стр]` | Очередь постранично |
| `!remove <номер>` | Убрать трек из очереди |
| `!move <от> <до>` | Переместить трек в очереди |
| `!shuffle` | Перемешать будущие треки очереди |
| `!history` | Последние проигранные треки |
| `!stop` | Остановить и очистить очередь |
| `!leave` | Выйти из голосового канала |
| `!volume [число]` | Показать или установить громкость (0.0–2.0, 1.0 = 100%) |

### Панель управления

| Команда | Описание |
| --- | --- |
| `!bot` | Открыть кнопочную панель: выбор плейлиста и действия с ним (▶ играть, 🔀 вперемешку, 📋 показать, ➕ создать, 🗑 удалить, ❌ закрыть). ▶/🔀 — бот подключится к твоему голосовому каналу |

### Плейлисты

| Команда | Описание |
| --- | --- |
| `!pl create <имя>` | Создать плейлист |
| `!pl add <имя> <ссылка> [<ссылка>...]` | Добавить треки (можно несколько сразу, а также аудиофайлом во вложении) |
| `!pl play <имя> [<номер>]` | Проиграть плейлист; с номером — начать с этого трека, дальше по кругу |
| `!pl shuffle <имя>` | Перемешать треки плейлиста и проиграть |
| `!pl replay` | Переиграть последний плейлист |
| `!pl list` | Список плейлистов |
| `!pl show <имя> [<стр>]` | Треки плейлиста постранично (с длительностями) |
| `!pl remove <имя> <номер>` | Убрать трек |
| `!pl rename <имя> <новое>` | Переименовать |
| `!pl delete <имя>` | Удалить плейлист |

Примеры:

```
!pl play Aboba
!pl play Aboba 5
!pl add Aboba <url1> <url2> <url3>
```

`!pl play Aboba 5` начнёт воспроизведение с 5-го трека плейлиста Aboba.

### Прочее

- `!help` — справка по всем командам, `!help <команда>` — детали.
- `!perms` — панель прав: владелец бота выдаёт/забирает права `control` (управление очередью), `playlists` (плейлисты), `permissions` (доступ к панели прав).
- `!status` — статус бота (сервера, очередь, кеш, uptime; только владелец).

## Установка и запуск

Требуется Python 3.10+ и установленный `ffmpeg` в PATH (Windows: `winget install Gyan.FFmpeg`, Linux: `apt install ffmpeg`).

```bash
python -m venv .venv
.venv\Scripts\Activate.ps1        # Windows (Linux/macOS: source .venv/bin/activate)
pip install -r requirements.txt
pip install -r requirements-dev.txt   # для тестов (pytest)
```

Токен бота: переменная окружения `LOLKA_TOKEN` или файл `token.txt` в корне проекта (создаётся автоматически с заглушкой). Приложение создаётся на https://lolka.app/developers.

Запуск:

```bash
.venv\Scripts\python.exe main.py   # Windows
python main.py                     # Linux/macOS
```

Тесты (без сети): `python -m pytest tests -q`. Бот — единственный инстанс: второй запуск завершится ошибкой (эксклюзивная блокировка `bot.lock`). Логи дублируются в `logs/music_bot.log`.

## Деплой на сервер

```bash
git push origin master
```

На сервере деплой применяется скриптом `deploy.sh` (вне репозитория).

## Структура проекта

- `main.py` — точка входа: консоль, патчи, бот, сборка cogs, файловый лог `logs/`, защита от второго инстанса (`bot.lock`).
- `config.py` — константы: токен, каналы, лимиты кеша и предзагрузки, нормализация громкости, параметры поиска.
- `util.py` — `setup_console()`, патч `parse_time`, `find_ffmpeg()`, `get_token()`, `acquire_single_instance_lock()`, `spawn()`.
- `ui_utils.py` — общие UI-утилиты: `esc()` (экранирование упоминаний/markdown), `fmt_duration()` (формат длительности), `paginate()` (универсальная постраничная разбивка).
- `engine_types.py` — TypedDict-классы для ключевых структур (`QueueEntry`, `PlayState`, `PlNav`, `PendingSearch`).
- `resolver.py` — `resolve_cached()` (трек из кеша или скачивание), `fetch_info()` (метаданные без скачивания), `search_youtube()` (поиск); отдельные пулы потоков на скачивание и метаданные.
- `track_cache.py` — `TrackCache`: локальный кеш (`cache/<video_id>.opus` + sidecar `.json` с title/duration/`loudness`), LRU-очистка по использованию, per-id блокировки от повторных скачиваний.
- `loudness.py` — измерение громкости (EBU R128, фильтр ebur128) и расчёт компенсирующего gain; при скачивании в кеш измерение ложится в sidecar, для вложений считается лениво.
- `upload_util.py` — аудио-вложения: скачивание в `uploads/`, санитизация имён, local-ссылки для плейлистов.
- `now_playing.py` — `NowPlayingView`: кнопки ⏮ ⏯ ⏭ 🔁 ⏹ ➕ на сообщении «Сейчас играет».
- `playlist_picker.py` — кнопка ➕ «В плейлист»: пикер плейлистов (кнопки, пагинация, создание через модалку, дедуп треков).
- `bot_panel.py` — панель управления `!bot`: выбор плейлиста, ▶/🔀/📋/➕/🗑/❌, подтверждение удаления, пагинация.
- `engine.py` — `MusicEngine`: очередь, воспроизведение, предзагрузка, история, цикл, плейлисты, поиск с выбором реакцией, нормализация громкости, автовыход при пустом канале.
- `playlist_db.py` — SQLite-хранилище плейлистов (с длительностями треков, миграция колонки `duration`).
- `permissions_db.py` — SQLite-хранилище прав (владелец бота на сервер + выданные права).
- `perms_panel.py` — панель `!perms`: выдача/отзыв прав через Select-флоу (участник → права).
- `cogs/` — команды: `music.py` (голос/очередь), `playlists.py` (`!pl`), `panel.py` (`!bot`), `perms.py` (`!perms`), `admin.py` (`!status`), `help.py`, `listener.py`.
- `tests/` — юнит-тесты (pytest, без сети): БД, ротация очереди, LRU кеша, громкость, пикер плейлистов, панель прав, resolver, now_playing, listener, хелперы.

## Зависимости

- `lolka.py` — официальный форк discord.py 2.7.1 под Lolka (WebRTC-голос входит в пакет).
- `yt-dlp` — извлечение аудио из YouTube (pytube не работает с текущим YouTube).
- `ffmpeg` — системный бинарник для декодирования аудио.
